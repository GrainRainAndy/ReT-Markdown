# Offline syntax samples

```cpp
#include <iostream>
int main() {
  // Offline C++ highlighting
  const int answer = 42;
  std::cout << "Hello" << answer;
  return 0;
}
```

```javascript
const answer = 42;
function greet(name) {
  // Offline JavaScript highlighting
  return `Hello, ${name}!`;
}
```

```unknown-language
const answer = 42; // Deliberately plaintext
```
