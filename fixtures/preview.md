## 从光标开始

在这段话中间按回车，然后在下一段开头按退格，观察文字和光标是否回到原位。试着选中 **这一段加粗文字**，剪切、粘贴，再撤销。

中文与 English 可以混合书写。字符边界样本：你好，世界；👨‍👩‍👧‍👦；café；é。

## 代码是一段字面文本

```python
def greet(name: str) -> str:
    # 中文注释也应保留
    return f"Hello, {name}!"

print(greet("世界"))
```

代码中的 `- item` 不应变成列表。普通回车留在代码块，块尾的 Command + Enter 创建块外段落。
