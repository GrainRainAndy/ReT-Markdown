# 编辑行为与状态转换契约

日期：2026-10-21。状态：用户已批准按[需求分析](requirements.md)开始实现，以下行为仍须逐项验证。表中规则是 ReT 的设计选择；与 Typora 相符的部分通过[证据索引](../research/typora-findings.md)标识，未知行为不以“Typora 默认如此”代替定义。

## 1 用例记录格式

每条用例记录 `beforeBytes / operation / afterBytes / beforeSelection / afterSelection / owner / historyGroup / allowedChangeRanges`。保存后再次核对磁盘字节。下文 `│` 为光标、`[文字]` 为选区，均不是实际内容；`\n` 表示 LF，具体字符串示例以 LF 夹具为准。CRLF 夹具中新插入换行采用 CRLF，混合行尾按当前块风格、文档主导风格、LF 的顺序选择，已有行尾不改变。UTF-16 用于内部文本坐标，实际键盘删除遵守字素边界。

所有修改还必须通过：Undo 回到操作前原文与选区；Redo 回到操作后状态；修改范围外字节一致；失焦/模式切换不增加修改；重开后语义相同。选区只移动、主题变化和渲染完成不进入内容历史。

## 2 输入、焦点和模式

| 编号 | 操作 | 必须得到的结果 |
| --- | --- | --- |
| E01 | 正文中文组词，预编辑中按 Backspace、选择候选、提交 | 系统组词过程完整，提交一次；候选阶段不执行段落合并或重建输入 DOM |
| E02 | 组词中触发保存/模式切换/关闭 | 自动保存可取最近已提交版本；手动动作等待真实提交/取消结果，超时保留窗口和文本，不伪造输入结束 |
| E03 | 组词中按 Esc | 由输入法取消预编辑；不误触发文档命令，不产生幽灵撤销项 |
| E04 | 依次编辑正文、代码、表格、源码，再连续 Undo | 沿同一根历史反向恢复；每步焦点回到相应位置，不调用错误局部历史 |
| E05 | 不编辑而切换实时/源码 20 次 | 字节、dirty、历史长度不变；逻辑位置往返稳定，视口保持同一内容锚点 |
| E06 | 源码模式改出未闭合结构后切回 | 原文原样保留；能呈现的部分正常显示，其余显示可编辑原文；不自动修复 |
| E07 | 公式异步渲染中移动光标或 Undo | 过期结果丢弃，不替换活动编辑 DOM，不把旧节点重新插回文档 |
| E08 | 两窗口交替输入、保存与撤销 | document/session 标识隔离，窗口间不串内容、选区或撤销 |

拖选期间延后会改变活动命中区域的重绘；释放鼠标后先提交逻辑选区，再更新视图。指针按下与释放之间不能先隐藏一个位置，再用旧矩形解释点击。

## 3 正文、标题和行内格式

| 编号 | 初态和操作 | 内容与位置契约 |
| --- | --- | --- |
| E09 | `Alpha│Beta`，实时 Enter | 源文 `Alpha\n\nBeta`；光标在 Beta 前，属于后段 |
| E10 | E09 后立即 Backspace | `Alpha│Beta`；一次结构合并，不需要先删除一个不可见空行 |
| E11 | `Alpha│Beta`，Shift+Enter | `Alpha  \nBeta`；使用两个空格产生硬换行，光标在 Beta 前 |
| E12 | 段尾连续 Enter，再输入 x | 每次新增空段落/间隔都有可编辑位置；保存源文保留用户创建的空白，失焦不合并。具体 LF 数由首个拆分两 LF、后续空段 Enter 每次一 LF 的规则确定 |
| E13 | 标题中间 Enter | 前半保留标题，后半成为普通段落；必要分隔符属同一事务 |
| E14 | Setext H1 改 H2；再改 H3 | H1→H2 只改变下划线形式；→H3 移除下划线并加入 ATX 前缀。Undo 恢复原长度与空白 |
| E15 | `**bold**` 可见内容完整选中后 Cut/Paste | Cut payload 为 `**bold**`，删除完整格式范围；粘贴后恰为一层强调。不能靠保存时格式化消除重复星号 |
| E16 | 只选 `**bold**` 中 `ol` 并 Cut | payload 为 `ol`，结果 `**bd**`；不扩张为删除整个 strong |
| E17 | 输入未闭合 `**`、反引号、`[` | 可继续输入、移动、撤销；仅有候选语法不自动吞字 |
| E18 | 中文、`👨‍👩‍👧‍👦`、`e` 加组合重音旁移动/删除 | 不出现半个代理对或残留组合字符；源坐标与可见字素导航分别正确 |

软换行保持其源文，实时渲染遵守方言语义。现有非规范段落、多个空行必须使用来源记录保留；E12 的新建规则不允许用于格式化已有空白。

## 4 列表和引用

| 编号 | 操作 | 契约 |
| --- | --- | --- |
| E19 | `* item│` Enter | 插入同层 `* ` 项；保持现有符号和缩进风格，原项不重写 |
| E20 | 空项 Enter | 退出一层；嵌套时先回到父级，顶层变为普通段落 |
| E21 | 有子项的条目 Tab/Shift+Tab | 以整个子树移动，不把 child 变为当前项的兄弟；没有合法目标时不改内容 |
| E22 | 从有序项续项 | 新项编号为前项+1，不修改其他已存在编号；任务项新增 `[ ]` |
| E23 | 空项开头 Backspace | 降一层或解除顶层列表，必要前缀作为一个事务删除 |
| E24 | 多项选区缩进 | 选中项及其子树去重后一次处理；前后树、源文及反向选区一致 |
| E25 | 引用内 Enter/空引用 Enter | 非空续当前层级，空行退出一层；代码或数学中的 `>` 不被接管 |

E21 的明确示例（结构而非字体缩进）：

```text
before: root -> [A, B -> [C]]
Tab B: root -> [A -> [B -> [C]]]
Undo:  root -> [A, B -> [C]]
```

同一规则适用于混合有序/无序/任务项；修改目标前缀时必须重新验证 Markdown 解析树确实与目标树相等。

## 5 代码和数学

| 编号 | 操作 | 契约与来源 |
| --- | --- | --- |
| E26 | 代码末尾 Enter | 插入一个字面行结束符（LF 夹具为 LF，CRLF 夹具为 CRLF）；即使位于未闭合 EOF 围栏，也保留代码归属。历史参考 TY-01/04 |
| E27 | 已闭合代码块尾、无选区 Cmd+Enter | 新建块外段落；Undo 恢复代码内位置。参考 TY-02；有选区或非尾部时不执行退出；未闭合块也不执行，提示先闭合且不增加历史 |
| E28 | 空代码起点 Backspace | 转为空段落；Undo 恢复围栏形式、语言、内容和焦点。参考 TY-03 |
| E29 | 代码内输入列表样式文字、Tab、粘贴 | 均为代码内容，Tab 按代码缩进规则；新输入默认两空格，已有 Tab 不改写 |
| E30 | 代码语言变更 | 仅改变围栏 info string；正文与选区保留，未知语言作为普通代码 |
| E31 | 数学 `- x│` Enter，再输入 y | 数学正文为 `- x\ny`，不续列表；尾 LF 原样保留。参考 TY-06，但刻意不采用其尾 LF 规范化 |
| E32 | 数学 `- │x` Backspace | 只删空格，得到 `-│x`。参考 TY-07 |
| E33 | 点击复杂公式、移出、再次进入 | 首次按确定入口进入源码，其后恢复映射后的书签；不以字宽猜测分式或矩阵位置 |
| E34 | 数学语法错误、超时或源文连续变化 | 显示原文/错误占位；最新版本恢复有效后才替换结果，不阻断正文 |
| E35 | 从代码/数学首尾用方向键跨块 | 仅到实际边界时交接 owner，内容不改变；Shift 扩选跨块仍保留方向 |

行内数学视为带源码编辑入口的内联对象。跨越整个对象的选择可复制/删除其完整 Markdown；在源码入口内选择只作用于内部源码。退出块数学使用与代码相同的尾部 Cmd+Enter 规则，包括未闭合时拒绝退出。例如源文 `~~~\nx` 的块尾 Cmd+Enter 后仍为 `~~~\nx`；`$$\nx` 同理，均不补闭合符。

实时模式的块级字面域边界采用对象选择：选区从代码或块数学内部跨出其结构边界时，明确扩展并显示为选中整个字面对象，包含完整开闭分隔符。默认复制、剪切和删除使用同一可见范围，不能只选中隐藏的闭合围栏，也不能在删除时才暗中扩大范围。仍在字面域内部的选区保持字符粒度；源码模式允许直接选择和编辑原始分隔符。此规则牺牲跨对象边界时的细粒度，换取可预期且不留下围栏碎片的操作；撤销恢复操作前源文与可见选区。

## 6 表格、对象与剪贴板

| 编号 | 操作 | 契约 |
| --- | --- | --- |
| E36 | 单元格输入中文、emoji、竖线与反斜杠 | 源文正确转义；不修改其他单元格的原始空白或对齐 |
| E37 | Tab/Shift+Tab | 行优先前后移动；首尾边界到表前/后正文；没有正文时创建必要段落，作为可撤销结构事务 |
| E38 | Enter/Shift+Enter | Enter 下移同列，末行退出表后；Shift+Enter 不改内容，并提示单元格不支持换行 |
| E39 | 增删行列、更改对齐 | 一个历史单元；操作范围只覆盖该表格。删除表头提升首个正文行，无正文行则转为空段落；删除最后正文行保留表头；删除最后一列转为空段落；全部可撤销 |
| E40 | 多单元格选择、跨表拖选、复制 | 显式保留单元格范围或文档文本范围；整单元格矩形复制按 TSV 纯文本、Markdown 复制按选中子表生成；非矩形文档选区使用文档范围规则 |
| E41 | 粘贴多行文字/TSV 到单个单元格 | 多行内容转为单行空格分隔文本，不自动增行列；粘贴为源码须先切源码模式，菜单提示该转换 |
| E42 | 剪贴板富文本、Markdown、图片、混合载荷 | 富文本默认取纯文本，Markdown 原文插入，纯图片导入资产，混合优先文字；明确命令可选择图片 |
| E43 | 选区默认复制/纯文本复制/富文本复制 | 三者 payload 独立核验；失败不改变内容；富文本不携带执行脚本或主动加载远程图片 |
| E44 | 图片复制尚未完成时 Undo/关闭 | 尚未提交的插入可取消；已提交引用可撤销，文件不自动删除；迟到回调不插回图片 |
| E45 | 查找隐藏语法并替换全部 | 必要时展开源码位置；一次事务，计数正确、Undo 完整恢复；不按可见 DOM 搜索 |

表格矩形选择只处理内容和范围，不引入表格计算或自动扩展。复制子表包含原表头时使用它；未包含表头时生成同列数的空表头与分隔行，所有所选行仍为正文，不能提升第一行并改变含义。例如仅选择一列正文 a、b，Markdown 为 `| |\n|---|\n| a |\n| b |`。原文不因复制被修改。E40/E41 是新产品规则，本轮尚无 Typora 原生表格对照支持。

## 7 通用边界组合

每组核心动作至少组合以下因素：正向/反向选区、空/非空内容、首/中/尾位置、LF/CRLF、闭合/未闭合语法、中文/emoji、实时/源码、失焦后再进入、Undo/Redo 后继续输入。

全量笛卡尔积没有必要；先覆盖所有条件分支，再用成对组合补相邻状态。真实 IME、跨块选区和保存关闭链为固定必测组，不能只保留合成 KeyboardEvent 测试。

## 8 2026-10-23 修复期状态矩阵（X01，非最终验收）

以下记录本轮明确的状态转换。自动证据区分模型与 Chromium；最终 WKWebView 键盘、真实 IME、保存重开和窗口关闭仍须使用同一构建复验，不以自动测试替代原生验收。既有 E01–E45 约束继续生效。

| 对象 | 进入 | 编辑 | 失焦 / 模式切换 | 退出 |
| --- | --- | --- | --- | --- |
| 段落 / 标题 | 点击或逐键形成 Markdown；菜单命令产生源文事务 | Enter 拆段、Shift+Enter 硬换行；标题剩余文本成为普通段落；仅修改需要的源文范围 | 不改字节；源码模式按逻辑选区映射；同一行前导缩进不生成空段，真实空白行仍可编辑 | 方向键与正文选区导航；Undo/Redo 使用文稿根历史 |
| 列表 / 引用 | 逐键、粘贴或菜单形成容器；源码模式可直接编辑标记 | Enter 续项 / 续引用；空项退出一层；容器中的字面域不执行列表规则 | 保持标记、缩进和行尾；失焦不规范化 | 空项 Enter / Backspace 按 E20/E23/E25；方向键跨块 |
| 代码开围栏 | 在正文逐键输入三个反引号或波浪号后，尚无换行的开围栏仍由正文编辑器显示源文，语言字符继续进入 info string | Enter 只添加一个所需换行，将 owner 与实际焦点一起交给局部代码编辑器；立即输入 `xhello` 无须点击 | 源码回到实时且选区在分隔符内时，入口约束到该字面域合法正文锚点；源码字节不变 | 进入正文编辑后按下一行规则；未闭合围栏不自动补闭合符 |
| 代码正文 / 块数学 | 点击字面源码；数学预览使用已有源码入口；菜单与源码切换复用同一映射 | 空正文从解析边界推导换行与容器续行前缀，支持裸开围栏、空闭合块、引用 / 列表嵌套、LF / CRLF；输入与连续 Enter 保持字面语义 | 不增加历史或修改源文；数学失焦折叠与代码高亮属于后续 X02，本轮不宣称完成 | 闭合块末尾 Cmd+Enter 创建块外段落；未闭合时拒绝且提示；空代码 Backspace 与跨块方向键沿用 E28/E35 |
| 行内数学 / 图片 | 点击对象；行内数学进入源码入口；链接图片 Cmd+单击通过既有链接桥接打开 | 继承外围 strong / link 标记；普通链接单击仍用于编辑 | 不因投影或导出丢失外围语义 | 对象范围复制 / 删除仍遵循完整源文范围规则 |
| 表格 | 表头列数决定实时与导出列数；缺格显示可编辑虚拟单元格，超额格隐藏 | Tab / Shift+Tab 按表头宽度逐格，Enter 同列下移；只有输入到缺格时才物化到该列所需分隔符，之后仍缺的格不预先补齐；粘贴按 E41 转义并变为单行 | 浏览、导航、失焦不改不齐原文；隐藏超额格保持原文，普通单元格编辑也不重写它们 | 首尾边界沿 E37/E38；物化与输入在一个根历史事务内，Undo 恢复不齐源文 |

本轮 Chromium 回归覆盖开围栏带 / 不带语言的连续键入、直接后续输入、Undo/Redo 后继续输入、源码往返、空特殊块无恢复提示、缺格导航 / 输入 / 粘贴及链接图片桥接。模型覆盖空特殊块的闭合 / 未闭合、LF / CRLF 与嵌套组合以及导出列宽和格式继承；既有反向选区、跨块、结构菜单和剪贴板套件继续作为回归门槛。保存重开、真实 IME、多窗口和原生 Cmd 键组合尚未形成这次修复构建的验收证据。

虚拟格的多个位置可共享同一个源文行尾锚点，必须同时保留现有 `Owner.cell` 的 `tableId / row / column`。投影内部 `virtual / missingBefore / needsSeparator` 仅用于物化缺格，不能序列化为 Markdown 或扩展宿主协议。`pendingOpening` 仅表示逐键形成、尚在正文编辑的围栏头；后续外观 / 失焦实现不得把该阶段错误当作正在编辑代码正文。
