# 0.1.0-rc.1 公式点击定位

2026-10-19 用户恢复工作。基准提交 `465505e`，上一轮间距修复仍在工作区；本报告只跟踪公式点击的新增修复，不将其计入正式 0.1.0 完整验收。

## RED 与根因

根会话在旧 QA `db08d01b` 的自有 `cursor.md` 中点击渲染 `$x+1$` 的 `1` 后侧，输入临时标记，AX 显示标记位于关闭 `$` 外。已单次撤销并保存，磁盘恢复 178 字节，SHA-256 `2f6f6ff111bedcd127946c6115178b0d61a39a67bf43a589da2d71b053b80420`。

新增浏览器回归从 `.katex-html` 中真实可见数字的 DOM Range 取点击点，完成实际鼠标点击后，源码期望位置 17（关闭 `$` 前），实际 14（表达式开头）。[初始 RED 日志](../../build/verification/0.1.0-rc.1/465505e-math-20261019/red.log)保留该失败。

`RenderWidget` 原点击处理丢弃坐标，与 Enter 共用固定 `span.from+1`。这是已确认的映射错误。原生与 Chromium 最终落点不同，与浏览器默认选区及 widget 展开的相互影响相容，但没有将其冒称为已经独立证实的事件竞争根因。

## 实现约束

Astra high 负责只读设计，Sol high 负责有界实现与回归，根会话负责首个 RED、原生 UI、打包和验证。只对可见字符与源码能逐字符核对的简单根公式映射；测实际字形前后边界，支持合并数字文本节点。不能映射的 TeX 使用既有揭示回退，不以公式总宽度猜源码位置。

仅可映射公式的普通主按钮按下阻止默认选区，并在旧 DOM 存在时计算位置及揭示源码；不使用定时器反复纠正 selection。Enter、图片、分隔线、复杂公式回退和唯一根历史保持。表格首击仍按原机制进入整个单元格源码，复杂 TeX 内部结构映射及表格内部公式精细命中不在此轮范围。

## 审查补充：运算符间隙

首版 10 个定向用例及完整 116 项浏览器通过后，根会话追加检查公式内部空隙。Astra 复核发现 Important：KaTeX 的 `+` 两侧 `.mspace` 没有文字节点，首版只接受字形矩形内部命中，空隙仍回退到表达式开头。新增真实间隙点击回归取得 RED，期望位置 16，实际 14。

已修正为仅在单行字形的紧致包围区域和共同高度带内，选择距离最近的真实字符边界；不扩至块公式整行宽度，不按总宽度估算字符。新增回归保留，独立复核通过；原先“通过”的审查结论由发现问题后的复核结果取代。
