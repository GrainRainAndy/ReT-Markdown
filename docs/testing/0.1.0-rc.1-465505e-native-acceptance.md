### 阻断缺陷：实时渲染点击与光标错位

用户手动反馈中文输入没有丢字，但鼠标点击与光标明显错位，标题、代码附近更明显，普通正文同样受影响。本次完整 IME 矩阵不能据此标为通过；暂停后续交付验收，先处理点击定位。

根会话原生复现：点击 AX 中可见“正文：”，截图中的指针停在正文，插入光标却落到下一块列表开头。新增 `web/test/cursor-hit-testing.spec.ts` 使用真实文字 DOM Range 的像素位置点击，而非从编辑器坐标接口生成预期；即使等待两帧布局，正文、列表、代码、末尾四项均失败。正文期望源位置 10，实际 15；列表 17→32，代码 30→68，末尾 110→114。失败日志为本次证据目录的 `cursor-hit-red.log`。

仅测试页去除垂直外边距的单变量实验使四项全部通过，表明渲染外边距与 CodeMirror 高度命中记录之间存在因果关系；实验没有修改产品源码，也不是最终排版方案。正在核对可保持既定视觉间距的修复。
