# 0.1.0-rc.1 原生抽查

2026-10-16。当前版本的有限原生工作流抽查通过；完整 V1 验收仍未完成。

## 环境与证据边界

用户重启后台后，Computer-Use 应用列表及原生窗口操作恢复。所有 UI 操作均通过 CUA 完成，未使用 shell 模拟点击或键盘。只操作工作区内独立身份的 `build/verification/0.1.0-rc.1/ReT Markdown QA.app` 和自有夹具；未替用户退出或覆盖原应用。

QA 副本来自已构建的 `build/releases/0.1.0-rc.1/ReT Markdown.app`，仅调整 bundle ID、名称及显示名并重新 ad-hoc 签名，以隔离文稿恢复。QA ID 为 `net.ret-markdown.qa.v0-1-0-rc-1`。本报告不把 QA 的隔离身份行为当作正式 bundle ID 下的生命周期验收。

最后核验资源逐字节一致；可执行文件因重新签名而哈希不同，在 `/private/tmp` 的临时副本移除签名后逐字节一致，未修改两个应用本体。两份包 strict/deep 签名均有效。除三处版本配置外，历史清单中 80 个文件保持原哈希；[核验清单](../../build/verification/0.1.0-rc.1/verification.json)记录结果及产物 SHA256。

CUA 调用出现一次自动审批超时，重试后恢复；另有一次 ScreenCaptureKit `-3811` 捕捉失败，后续 AX 与截图恢复。工具调用等待不用于计算应用启动或输入性能。先前未版本化 QA 的空窗口及进程变化原因未确认，不据此认定崩溃或恢复通过。

## 实际操作与结果

| 操作 | 实际观察／核验 |
| --- | --- |
| 原生打开 | CmdO、系统路径面板选择已落盘的 `expected-smoke.md`，点击 Open；AX 显示正确文件 URL 与版本化 QA 资源路径 |
| 引用公式 | 将光标移至文末，截图显示引用竖线及正确的居中分数 1/2；没有把引用标记渲染为 TeX 内容 |
| 表格查找 | CmdF 输入 `---:`；首次 Return 未观察到变化，随后点击 next，表格展开为原始三行 Markdown，截图显示对齐分隔行的紫色命中；没有据此宣称 Return 快捷键通过 |
| 原生另存为 | Escape 关闭查找，CmdShiftS 打开系统保存面板；提交 `native-smoke.md` 后窗口 URL 更新。原生字段需实际输入触发启用；最终文件名按 AX 校正后点击 Save |
| 保存字节 | `cmp expected-smoke.md native-smoke.md` exit 0；81 字节，LF、无末尾换行，与夹具完全一致 |
| 原生 PDF 导出 | CmdShiftE 打开系统保存面板，点击 Save 生成 `native-smoke.pdf`，16,741 字节 |
| PDF 核验 | Poppler `pdfinfo` 显示 1 页、595×842 pt A4；`pdftotext` 可提取 before/after、表头与左右单元格及分数数字；PNG 人工检查显示白底、正确分数、表格及右对齐，无裁切或重叠 |

夹具与保存文件 SHA256 均为 `bfb414910d5c74f6fabe79a11f032dddd1c2fde5fcb767554cdf38369f9cfe3a`。AX 和窗口截图由 CUA 返回并在会话中核验，没有宣称截图另存到文件。PDF 渲染 PNG 是独立生成的持久文件。
