## 语义与实现

- 只有实时模式、非空顶层普通段落的 Enter 在当前选区局部插入两个 LF；光标位于插入末端。源码模式仍为单 LF，普通空行也是单 LF。新 EOL 沿用当前行，原有混合 EOL 与 BOM 保留。
- 复用实际 Markdown 渲染器的块语法判断普通段落及闭合/未闭合数学范围；代码、行内字面代码/图片源码/HTML 标签/链接目标、列表、引用、标题、表格及公式保留原有行为。列表继续与空列表退出先按原逻辑处理。不整理周围已有换行，不把全部 source 换行改成段落。
- 每段连续普通根空行中，第一个仍是 Markdown 结构分隔，额外行则保留为真实可编辑 CM 行。活动范围只覆盖空行自身，不因下一行光标误揭示上一结构分隔。额外行不再依赖焦点，因此离开后不消失。
- 仅给可见普通空行及不属于容器的空 EOF 行设置左 padding 0，与实时正文一致。源码模式、代码、列表和引用等继续使用各自内边距。普通段落 CSS 间距与 CM viewport/height-map 机制保留；额外行只添加自己的行高。

见[Enter 方案](../plans/2026-10-20-0.1.0-rc.1-live-paragraph-enter.md)与[空行方案](../plans/2026-10-20-0.1.0-rc.1-blank-line-projection.md)。
