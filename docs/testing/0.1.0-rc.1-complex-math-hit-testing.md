## 行为与设计

点击真实字形的前后侧，选择其实际 TeX 源码区间的起点或终点。例如分子 `1` 的后侧进入 `{1}` 中的 `1` 后；希腊字母 `α` 的后侧进入 `\alpha` 末尾。公式规则线、根号图形和无法证明来源的宏展开保持揭示源码回退，不按公式总宽度猜位置。

Markdown tokenization 保留每个 TeX 字符的原始 UTF-16 起止位置，涵盖 CRLF、块引用/列表前缀和表格管道转义。KaTeX 0.19.0 私有适配器将解析叶子的源码区间附加到原有字形节点；不插入叶子包裹元素，不改变原生字符合并。依赖版本与私有结构的维护限制见[架构设计](../plans/2026-10-19-0.1.0-rc.1-complex-math-mapping.md)。

表格在 mousedown 阶段读取尚未被销毁的公式 DOM，以原始 token 区间定位，经过 `cellOffset` 映射到单元格编辑器；先安装目标选区，再转移焦点并同步根选区。重复公式不通过文本搜索定位。保留唯一根撤销栈、组合输入屏障和搜索面板焦点，见[表格计划](../plans/2026-10-20-0.1.0-rc.1-table-math-mapping.md)。

### 联测发现的整数坐标边界

首次有效 55 项联测为 54 PASS、1 FAIL：点击行内分母 `2` 前侧，期望根位置 17，实际回退至 8。真实字形矩形彼此没有重叠，不能把早期“重叠”假设作为根因。

`denominator-gesture.json` 记录：分母左边界 x=248.3125，取点 x=248.984375；helper 对原始浮点点位返回相对偏移 10，但真实 `mousedown.clientX` 截断为 248，落在矩形左侧 0.3125 CSS px，因此未命中。已补充测得矩形的单元 RED/GREEN，并保留浏览器真实手势失败回归。

修复优先采用精确命中；仅在没有精确命中且坐标为非负整数时，检查 `[x,x+1) × [y,y+1)` 像素范围是否唯一地与一个字形相交。多个候选仍回退，不将复杂公式改为宽度比例、文字顺序或大范围最近字形猜测。修复后 55 项及完整 152 项浏览器均通过。
