# 0.1.0-rc.1 渲染光标定位修复记录

2026-10-18，基准提交 `465505e747b591d262247d52d6cbfac9da0099ee`。这是未提交工作区修复的过程记录；正式 0.1.0 尚未通过完整原生验收。

## 复现与根因

用户手动反馈实时渲染点击与光标错位，普通正文也受影响。根会话在 QA 中点击正文，实际光标落到列表；同一文稿切源码模式点击正常。基础四项 DOM Range 实际鼠标点击全部失败，扩展六项实时案例失败，源码对照通过。仅测试页清除垂直 margin 的单变量实验使基础四项通过，未据此取消产品间距。

CodeMirror 先按累计高度选块，再扫描该块文字。实时投影的外 margin 不包含在叶节点矩形测高内，使文档实际布局高于命中记录。修复将折叠后的间距放入可测量 wrapper，语义盒子的字体、背景、边框和内部 padding 保留。

## 分工与范围

- Astra high：根因分析和 `web/src/live/decorations.ts`、新 `web/src/live/spacing.ts` 的复杂布局修复。
- Sol high：新 `web/test/cursor-hit-context.spec.ts`，覆盖标题、代码、引用、滚动、0.75/1.5 缩放、无尾 LF、源码对照及 BOM/EOL 撤销。
- 根会话：原生 UI、基础点击回归、独立检查、文档和后续新包验收。没有写 Git。

## 中间结果与发现

基础四项点击首轮修复后通过；13 组诊断文稿的语义块位置、宽高及实际文档高度与修复前一致。多数无尾 LF 文稿约 0.7969px 的末尾测高差来自依赖对 content padding 的 `parseInt`，不能报告绝对零误差。

全量浏览器首轮为 99/106 通过。未通过项为：75% 缩放滚动后的点击、四项表格退出后重新点击的焦点交接，以及两项直接断言旧 margin 属性的排版测试。前五项属于必须处理的行为问题。

两项排版测试在 `editor.spec.ts` 中改为验证相同的可见间距：标题间距 16px，代码块前后 15px；字体、行高、边框、颜色和内部 padding 断言保留。针对运行 2/2 通过。没有放宽距离容差、超时或原有投影几何断言。
