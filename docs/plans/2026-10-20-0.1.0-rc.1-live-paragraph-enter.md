# 实时普通段落 Enter

原生验收 `NATIVE-ENTER-01` 确认单 LF 导致普通段落失焦后被 soft break 合并；用户明确要求建立新段落。保留用户 `native-core.md` 未保存修改及既有包，仅在自有夹具与新 QA 中验证。

实时模式中，非空顶层普通段落的 Enter 在选区处插入局部 `\n\n`，光标位于插入末端。已有换行不整理、不替换，新换行沿用原行 EOL，撤销复原原字节。普通空行仍插入单 LF，额外空行的稳定投影另由 blank-line 修复处理。

源码模式仍为单 LF。列表继续/退出、代码块及行内代码、引用、标题、表格、HTML、块公式与未关闭公式均保留既有处理。复用实际渲染器的顶层 paragraph token 与数学源码区间分类，避免新建不同语法的第三套 parser；行内 code 依照已有 Lezer 节点排除。通过只读 getMode 将模式传给命令层，键盘与 format command 共用相同规则。

已先取得 38 项定向单元中的 7 个 RED（31 个结构/source 控制已通过），真实键盘浏览器两模式对照中 live RED/source PASS。新增单元检查普通段落中间/开头/末尾、文档末尾、多行 paragraph、反向选区替换和 BOM/CRLF 字节撤销。浏览器检查真实 Enter、撤销/重做、键入 NEW、点击另一段后仍保留独立段落。最终需与空行投影整合后独立审查、新路径打包及原生复验，不操作 Git。
