# Table formula hit mapping supplement

Scope: `web/src/live/cell-widget.ts` and a new focused
`web/test/table-math-hit-testing.spec.ts`. The root integration and shared math
renderer/hit helper belong to the parent and Astra respectively. No Git writes,
native UI, application build, other source/test edits, or additional agents.

## Contract and event ordering

- Successful rendered formulas carry `data-math-from` / `data-math-to` as original
  full-document UTF-16 bounds. Use that exact source slice, never a string search
  for a formula which may occur repeatedly in the same or another cell.
- `mathHitOffset(wrapper, originalSource.slice(from, to), false, x, y)` returns a
  raw offset relative to that slice, or `null` to preserve ordinary cell focus.
  Raw table escaped pipes must remain accounted for by the helper's mapping.
- Inspect primary, unmodified, uncanceled `mousedown` before host focus erases
  rendered HTML. Accept only a wrapper contained by that host and integral bounds
  contained by the current actual cell and current source.
- Convert `from + offset` with `cellOffset(cell, absolute, -1)`. Prevent native
  default, create the mini editor without mirroring a provisional zero position,
  install the mapped selection while syncing, then focus and mirror once. A
  complete mouseup/click gesture must not reset that position or steal focus.
- Preserve existing ordinary click/focus, search focus, and sole root history.
  Do not switch cells while either a mini editor or the root is composing. Keep
  the existing read-only policy; the precise-mapping path must not bypass it.
