# 0.1.0-rc.1 实时渲染光标定位修复

2026-10-18。对应用户原生验收反馈：中文输入未丢字，但实时渲染下点击正文、标题、代码附近，光标明显偏离。作为阻断缺陷处理，正式 0.1.0 交付仍待验收。

## 根因证据

- 同一 QA 原生文稿，源码模式点击正文正确；实时模式点击正文落到列表。
- `cursor-hit-testing.spec.ts` 从可见文字的 DOM Range 获取像素位置并真实点击，等待布局两帧后四项失败。源码位置：正文 10→15、列表 17→32、代码 30→68、末尾 110→114。
- 单变量实验仅在测试页清除垂直 margin，四项全部通过；产品未因实验修改。
- CodeMirror 的 `measureVisibleLineHeights` 累计叶节点矩形及 wrapper 内部上下余量，未累计相邻块的外 margin。实时投影引入的段落、标题、代码、widget 外 margin 让实际页面高于命中记录，点击先选错后续块。原生坐标缩放及输入法均不是该复现的必要条件。

## 修复范围

将实时投影中的块间距移入 CodeMirror 能测量的无视觉样式 wrapper。保留现有语义盒子的字体、边框、背景和内部 padding；按原正 margin 的折叠结果计算相邻间距。隐藏空行不制造额外高度，可见源码空行保留实际边界。引用内部单独处理，表格与公式内部已包含的间距不重复计入。

不增加文档或历史副本，不修改源文、换行、BOM、表格映射及输入法协议，不修改 CodeMirror 私有字段或依赖源码。投影计算保持线性或 O(n log n)。
