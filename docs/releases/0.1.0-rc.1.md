## 版本与构建

`package.json` 的 `version` 是唯一发布版本来源；lockfile 的根版本同步为 `0.1.0-rc.1`，依赖版本保持不变。执行 `bash scripts/build-app.sh` 时，从该版本生成默认输出路径及包内信息：

| 字段 | 值 | 用途 |
| --- | --- | --- |
| `CFBundleShortVersionString` | `0.1.0` | 三段整数的 macOS 发布版本 |
| `CFBundleVersion` | `1` | 源 Info.plist 中保留的数字构建号 |
| `ReTReleaseVersion` | `0.1.0-rc.1` | 完整预发行版本 |
| 产品显示名 | `ReT Markdown` | 保持现有名称 |

`RET_APP_OUTPUT` 继续支持指定完整 app 输出路径；它只改变路径，包内版本仍来自 `package.json`。后续正式版须将 canonical 版本改为 `0.1.0`、同步 lockfile 根版本并重新构建校验，不能仅重命名 RC 文件夹。字段格式与历史静态检查见[版本整理报告](../testing/versioning-report.md)。
