## 版本与构建

`package.json` 的 `version` 是唯一发布版本来源；lockfile 的根版本同步为 `0.1.0-rc.1`，依赖版本保持不变。执行 `bash scripts/build-app.sh` 时，从该版本生成默认输出路径及包内信息：

| 字段 | 值 | 用途 |
| --- | --- | --- |
| `CFBundleShortVersionString` | `0.1.0` | 三段整数的 macOS 发布版本 |
| `CFBundleVersion` | `1` | 源 Info.plist 中保留的数字构建号 |
| `ReTReleaseVersion` | `0.1.0-rc.1` | 完整预发行版本 |
| 产品显示名 | `ReT Markdown` | 保持现有名称 |

`RET_APP_OUTPUT` 继续支持指定完整 app 输出路径；它只改变路径，包内版本仍来自 `package.json`。后续正式版须将 canonical 版本改为 `0.1.0`、同步 lockfile 根版本并重新构建校验，不能仅重命名 RC 文件夹。字段格式与本次静态检查见[版本整理报告](../testing/versioning-report.md)。

## 正式版仍需完成的验收

- 真实中文 IME 的候选、组词、取消、删除与撤销。
- 完整原生生命周期矩阵，包括两种系统关闭设置、退出重开、Versions、外部修改与冲突处理，以及连续编辑保存、图片和剪贴板工作流。
- 与 Typora 在相同视口、缩放和浅深色下的完整视觉对照。
- 原生 Release 冷启动、打开、输入、RSS、IME 与 PDF 的规定性能序列；历史浏览器性能和单次 PDF 运行不能代替。

此构建仍采用本地 ad-hoc 签名，尚非已公证的分发版本。切换候选前先保存文稿并退出旧版，再从版本化路径打开，避免同 bundle ID 将打开请求路由至旧实例。
