## 特殊块与依赖

离线语言范围：`js/javascript`、`c/h/cpp/c++/cc/cxx/hpp`（C 家族使用 C++ grammar）；其他语言包括 Python/TypeScript 为纯文本。`@codemirror/lang-javascript 6.2.5`、`@codemirror/lang-cpp 6.0.3`、`@codemirror/language 6.13.1`、`@lezer/highlight 1.2.5` 被 lock 固定。采用 parser-only language 和 `syntaxHighlighting`，不引入自动补全、自动闭合或局部历史。`THIRD_PARTY_NOTICES.md` 包含新增运行时依赖和传递依赖许可证及 lock 哈希，可用 `python3 scripts/update-notices.py` 重建。

API 核查使用官方 [JavaScript 包说明](https://raw.githubusercontent.com/codemirror/lang-javascript/main/README.md)、[C++ 包说明](https://raw.githubusercontent.com/codemirror/lang-cpp/main/README.md)、[HighlightStyle / syntaxHighlighting 源码](https://raw.githubusercontent.com/codemirror/language/main/src/highlight.ts)、[Compartment 源码](https://raw.githubusercontent.com/codemirror/state/main/src/facet.ts)，并核对安装包类型定义。官方 GitHub 镜像已注明迁到维护者 forge；没有加载远程语法资源。

数学折叠只隐藏现存标签和 CodeMirror DOM，不替换它们。提交沿用 commit-before-`composition(false)`；根投影若恢复字面域焦点，就继续显示源码。焦点离开后的折叠等一帧，让浏览器先安装目标段落选区，再补偿可滚动范围内的阅读锚点。旧 preview/error HTML 从未写入源文。屏幕折叠与打印渲染无关。
