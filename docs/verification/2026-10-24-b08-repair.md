## 复现和因果证据

本轮先在 alpha.2 的专用 `Untitled 3` 文稿独立复现：系统拼音 `ni` 预编辑中点红色关闭，空格提交，取消关闭，不点击正文再次 `ni`＋空格，得到 `你ni你`。用户已手动确认该窗口系统拼音候选可用。

隔离诊断副本使用 alpha.2 原生源码和 Web，增加只读事件记录与隔离恢复目录。它复现 `B08-TRACE 你ni你`；同一副本取消关闭后先点击正文的对照路径只追加“你”。日志记录：

1. 关闭等待提交完成后，将 workspace 设为 inert；编辑器失焦至 BODY。
2. 取消关闭只解除 inert，没有恢复编辑器焦点。
3. 后续实际系统预编辑没有发出 compositionstart；第一个 insertCompositionText 到来时 activeElement 仍为 BODY，随后才出现 focusin。`ni` 被写入源文本，提交事件又追加“你”。
4. 修复诊断版在 release 时先恢复 ProseMirror 焦点；下一次输入正确产生 compositionstart，组合态不写入源文本，提交后显示 `B08-FIX 你你`。

事件记录中的 `source` 字段来自 DOM textContent，不能单独证明 Markdown 磁盘字节正确。正式候选另做保存/重开核验。

## 实现

`editor/main.ts` 在第一次取得关闭输入锁时记录正文是否拥有焦点。重复 flush 不覆盖该记录。释放实际取得的锁时，通过现有 rich/literal 的 owner-aware focus 恢复原编辑表面；load 清除记录。恢复草稿、外部替换和活动组合态仍保留屏障；没有取得锁的 release 不抢占其他控件焦点。没有改写或清除拼音字符串，没有修改原生输入法事件。
