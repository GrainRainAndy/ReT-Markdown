# 从零重写验收方案

日期：2026-10-21。状态：待实施的验收规格。旧版本通过记录不继承，新产品目前没有测试通过或发行就绪的结论。需求见[requirements](../specs/requirements.md)，编辑用例见[editing-contracts](../specs/editing-contracts.md)。

## 1 证据层级

| 层级 | 能证明什么 | 不能替代什么 |
| --- | --- | --- |
| L1 纯核心测试 | 原文补丁、结构树、位置映射、历史、资源状态机 | 真实 DOM 输入及系统文稿行为 |
| L2 浏览器集成 | 正文和局部适配器的实际键盘/鼠标/DOM 事件、剪贴板测试载荷 | WKWebView、真实输入法与系统剪贴板互操作 |
| L3 macOS 原生 | WKWebView、系统 IME、菜单、窗口焦点、NSDocument、文件授权、恢复 | 不能只截一张图就证明所有状态正确 |
| L4 输出/性能 | PDF 实际字节、分页、文本提取、内存和延迟原始样本 | 不能用解析耗时替代输入到屏幕的耗时 |

每个结果记录构建 commit、完整输入清单哈希、bundle 哈希、macOS/硬件、参考版本、夹具 hash、步骤及实际结果。视觉比较额外记录字体、视口、缩放和配色。当前 branch 名或文件路径本身不是构建身份。

## 3 固定夹具

建立新的人工编写夹具，不复制旧实现逻辑来生成期望值。可复用历史失败场景的思想，来源要标记为 legacy regression reference。

| 夹具 | 必含内容 |
| --- | --- |
| bytes | BOM、LF/CRLF 混用、EOF 无 LF、多个空行、不同列表符号、转义、未知扩展 |
| structures | 嵌套列表和引用、Setext、复杂表格、引用式链接、未闭合围栏 |
| input | 中英混输、emoji ZWJ、组合音标、中文标点、候选取消及重复提交风险 |
| literal | 代码/数学中的列表样式文字、空块、末尾空行、未闭合 EOF、复杂公式 |
| assets | 中文/空格/特殊字符路径、同名不同内容、缺失/大图/SVG、远程占位 |
| print | 页末标题、跨页代码/表格、长 URL、宽公式、透明图、中文与混合字体 |
| adversarial | 极深嵌套、超长单行、恶意 HTML/SVG/链接、失效桥接 epoch 与过大 payload |
| perf | 固定字节数的纯文本及混合 1 MiB 文档，记录节点/公式/图数量与字体 |

夹具与操作脚本分别冻结，避免测试运行时重新生成“正确答案”。随机编辑测试记录 seed；每步与全量解析、逆补丁和字节范围不变量比较。

## 4 文件生命周期故障矩阵

| 编号与追踪 | 故障注入点 | 必须观察的结果 |
| --- | --- | --- |
| F01 · A05 · R-FILE-02 | 保存请求已取 revision N，用户输入至 N+1 | 磁盘可为 N；dirty 仍真；N+1 可随后保存 |
| F02 · A05 · R-FILE-02 | 文件写到临时文件时 ENOSPC/EACCES | 原文件完整，最新正文和草稿可用，无 saved 成功消息 |
| F03 · A07 · R-ASSET-01 | 图片部分复制成功、文稿失败 | journal 可重试，无已保存的断裂引用，不删除源图片 |
| F04 · A07 · R-ASSET-01 | 同一 operationId 重复请求 | 不重复复制、不重复插入，结果一致或可查询 |
| F05 · A06 · R-FILE-03 | 外部程序在保存/输入期间改文件 | 协调失败/冲突可见，不静默丢弃一方 |
| F06 · A05/A06 · R-EDIT-03 | flush 期间组合输入未结束 | 保存/关闭保持 pending；超时提供重试/取消，不丢最后一字 |
| F07 · A06 · R-FILE-03 | 关闭取消后迟到回调 | 仍在同一有效会话时按协议处理；已失效 epoch 的回调不影响文档 |
| F08 · A05/A06 · R-FILE-02 | WebContent 进程退出 | 恢复到最后宿主 received checkpoint，报告未确认编辑风险 |
| F09 · A05/A07 · R-ASSET-01 | 系统恢复/首次保存中途终止 | 重开可识别完成/未完成 journal，继续恢复，不重复迁移 |
| F10 · A08 · R-PDF-01 | 导出中编辑、旧 job 迟到 | 输出固定内容/资源版本，旧结果不能更新新作业 |
| F11 · A05 · R-EDIT-01/R-FILE-02 | 适配器 Step 无法转换 | RecoveryDraft 保留；flush 明确 pending，Undo/关闭不覆盖可见草稿，源码恢复后可提交 |
| F12 · A05 · R-FILE-02 | 宿主进程被终止、恢复文件写入中断、当前记录损坏 | 分别恢复最后 durable checkpoint 或上一有效记录；正文与资源校验通过，未持久化风险可见 |
| F13 · A06 · R-FILE-03 | 放弃修改前后有排队保存及正在替换的作业 | 先结算不可取消作业，再确定磁盘基线；放弃后未提交作业不能再写盘，禁止仅丢响应而照常保存 |
| F14 · A05/A07 · R-FILE-02/R-ASSET-01 | 另存冻结 N 后输入至 N+1，资源迁移失败/成功 | N 的内容和资源一致；失败不换身份，成功后 N+1 仍可保存且 dirty 正确 |
| F15 · A05 · R-FILE-02/R-FILE-03 | 系统“浏览所有版本”选择旧版，含本地修改/缺失历史图片 | 先处理本地修改并保留恢复记录；接受后新 epoch/历史，旧版字节明确、缺图占位可见；取消保持当前会话 |
| F16 · A04/A06 · R-FILE-01/R-FILE-03 | 外部重命名/删除、冲突选择期间再次变化、取消冲突 | 不静默重建文件；接受前重验外部版本；取消不失效本地 epoch；待持久化资源阻止自动重载 |
| F17 · A08 · R-PDF-01 | 分别在最终替换前、与替换竞争时、替换后取消 | 协调点先收到取消则不替换；已提交则报告完成，不得同时声称取消成功；旧 PDF 字节在成功取消时不变 |

## 5 交付门槛

G1/G2/G3/G4 对应[技术方案](../architecture/technical-design.md)中的准入条件。每个必需需求须覆盖追踪矩阵中的全部必测子场景，E01–E45 与 F01–F17 均需有效通过记录；不能以一条保存成功代替整个保存/恢复需求。未测标记为未测，参考软件未知行为标记为未知，不统一写成“通过”。

核心输入、保存、保真、撤销、恢复有已知失败时不能发布正式版本。视觉轻微偏差也必须记录具体场景与影响，不用“总体类似 Typora”替代对照结果。所有接受的偏差需形成新的需求版本。

新实现的测试命令和依赖版本在建立正式工程时补充；此文仅定义验收方法，不能引用旧 `npm test` 或旧构建成绩证明新版本正确。
